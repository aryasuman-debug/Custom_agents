# Custom_agents
This repo is having all the AI agents required for automation testings

# Folder Structure
- .github/agents: This folder contains all the agents that are responsible for generating test documents
- .github/behaviours: This folder contains all the behaviour files that are used by the agents to generate test cases
- documents: This folder contains all the input documents such as SRS, user stories, acceptance
- criteria, etc. that are used by the agents to generate test cases
- test-documents: This folder contains all the generated test documents such as test cases, test
- strategies, test plans, etc. that are generated by the agents
- README.md: This file contains the overview of the repo and its structure
- .gitignore: This file contains the list of files and folders that are ignored by git

- mcp.json - This file needs to be in the root directory of the repo and contains the configuration for the agents and this should not be pushed in the repo.
- There is a placeholder for the jira and the gitlab tickets and rest of the steps are in the attached documents.
